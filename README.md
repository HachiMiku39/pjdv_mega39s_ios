# PJDV M39 · iPadOS / iOS / macOS 测试版

《初音未来 Project DIVA MEGA39’s》Switch JP v1.0.9 的 Apple Silicon 兼容移植研究。原游戏 ARM64 程序经 Horizon 服务兼容层运行，图形通过 **NVN → Metal** 输出。

**0.1.5（build 7）｜2026-10-21｜兼容性预览版。** GitHub 只发布不含游戏资源与密钥的精简安装包；本地完整测试包保留在外置 SSD。

## 0.1.5 更新与验证范围

- **降低安装门槛**：iOS／iPadOS 最低 17.0，最低 GPU 为 Apple family 7（A14／M1 同代），iPhone 同样开放。iOS 使用已有 Metal 3 兼容提交路径，macOS 仍要求 26+。
- **低配档（family 7／8）**：首次默认 720p、标准画质，最高输出 1080p；禁用 HDR、光追和 60→120。MetalFX Spatial 根据实际设备能力提供。低配的分辨率与画质单独保存，旧高配设置不能绕过输出限制。
- **30→60 模拟器实验**：iPhone 18 Pro／iOS 27.2 的独立合成场景通过中间帧读回、开关对照、切镜头、暂停恢复及重新进入检查。模拟器没有 MetalFX 框架，采用明确标注的替代算法；这不是实际游戏或苹果 MetalFX 插帧验收。独立插帧实验需要 iOS 26，真实游戏插帧尚未接入。

**本版为兼容性预览：** iOS、模拟器和 macOS 构建通过，family 7 限制档在 iPhone 18 Pro 模拟器可显示片头、标题和主菜单，720p／1080p 输出正常。**尚未在 iOS 17、M1／A14 真机验收**，也未验证 4 GB 内存设备的稳定性、全曲帧率和高配设备改走 Metal 3 后的 HDR／RT 回归。模拟器约 60 FPS 的菜单数据不代表旧设备性能。

## 本轮改进

- **场景与景深**：修复两条片元着色器的透明度控制流，以及 NVN 到 Metal 的深度范围转换。在已抽查的《39みゅーじっく！》镜头中恢复立方体表面、发光圆环、大屏内容和人物对焦；这不代表所有歌曲或光照已完全还原。
- **载入**：本体和 27 DLC 共用原生 FARC/gzip 解压路径；477,748 个压缩条目的内容核验通过。收益取决于歌曲资源组成，仍不能保证所有歌曲都瞬间载入。
- **独立渲染依赖**：精简包内附匹配的 Metal 着色器与反射缓存，资源导入后不依赖开发机的缓存目录。
- **iPhone 实验适配**：开放满足 Apple GPU family 7 的 A14 同代及更新设备（兼容性预览）；最高 1080p、60 FPS，隐藏 1440p、屏幕分辨率输出和 120 FPS 选项。手机布局与折叠姿态先在模拟器验证。
- **折叠布局**：展开居中显示，合上横屏，半折分为上部游戏和下部控制区；保留原比例，利用自然黑边放系统状态栏。折叠模拟器适配不等同于真实折叠设备验收。
- **摇杆编辑**：启动页可调整左右虚拟摇杆的大小与位置，按手机、平板及折叠姿态分别保存；折叠设备默认摇杆缩小。
- **语言对应**：选择日文、简体中文或繁体中文时，宿主界面与游戏使用同一语言。真机发现英文字符串表并不等于完整英文菜单：这份 JP 包会混用日文图片，因此暂不开放英文、韩文选项；旧设置选到这些语言时统一回退日文。少数底层诊断仍保留技术文本。
- **手柄图标**：新增按实体手柄类型选择游戏图标的路径，Xbox 的旋律预览顺序为 **Y、X、A、B（上、左、下、右）**；PS 复用原有符号素材，保留箭头模式和既有输入映射。M4 iPad 已用诊断指定 Xbox 图标验证主菜单/设置底栏、YXAB 预览和按键设定；本轮未连接 Xbox 实体手柄，热插拔识别与完整谱面仍待更多实测。部分预烘焙帮助图、标题 Press A 和中央手柄示意图仍显示原版标识。

## iPad 安装与首次启动

1. 给 IPA 使用你自己的有效开发签名，安装到受该签名允许的 iPad / iPhone。公开 IPA 未签名，不能靠把文件拷到 iPad 就完成安装。
2. 按系统要求启用 [开发者模式](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device)。如系统要求信任开发签名，在“设置 → 通用 → VPN 与设备管理”处理对应开发者。
3. 打开 PJDV M39，使用下面的 XCI 导入或已提取资源方式。资源未就绪时“启动游戏”不可用。
4. 点击“启动游戏”，用虚拟 A、键盘 D 或实体手柄的确认键进入。A 可以跳过开头视频。

本地 development IPA 的签名只覆盖当前登记设备，并有有效期；换 iPad 需要重签。更新测试版尽量覆盖安装，先备份存档再做卸载操作。

### 方式一：直接导入 XCI

1. 在首页打开“导入 XCI／资源管理”。公开版先点“选择／更换 prod.keys”，选择本地密钥文件；本地内置密钥版可跳过这一步。
2. 点“导入 XCI”，选择匹配版本的 `.xci`。ZIP / 7z 需先解压；云端文件需先下载完整。
3. 保持 App 在前台，等待基础资源、v1.0.9 更新合并及 27 DLC 导入完成，再点“完成 → 启动游戏”。

XCI 若在外置盘，可直接读取源文件，输出资源写入 iPad 本机。此包资源约 **41.94 GB**，建议给输出预留 **45 GB** 可用空间；若 XCI 也先拷到本机，则还要计入约 **42.72 GB** 的源文件空间。取消后再选同一 XCI 可以续导；断开外置盘、空间不足或校验失败会停止，原 XCI 与存档保留。

### 方式二：使用完整测试包内已提取的资源

已有本作完整资源的设备只需更新 IPA，无需重复拷入资源。

1. 在 Mac / 外置 SSD 上解压本地 FullTest ZIP，不必重新从 XCI 提取。
2. 安装并至少打开一次 App。用线连接 iPad，在访达打开“iPad → 文件 → PJDV M39”，拷入完整的 `GameResources` 文件夹。
3. 等传输完全结束；打开 App 的资源管理，选择“使用已拷入本机的资源”。也可在“文件”App 中连接已准备好的整个资源目录。

必须保留准备完成的清单文件和文件夹结构，不要只拷贝 `rom` 子目录：

```text
PJDV M39 的 Documents/
└── GameResources/
    ├── romfs/                 # 也兼容 MEGA39-v1.0.9 这个目录名
    │   ├── preparation.json
    │   ├── complete.json
    │   ├── files.jsonl
    │   ├── rom/
    │   ├── rom_switch/
    │   ├── shader/
    │   └── ……
    └── DLC/
        ├── manifest.json
        ├── 1/
        ├── 2/
        └── ……                # 共 27 个，编号不连续，不要重新编号
```

也可以直接连接外置盘上已提取的目录；运行期间需一直连接。若希望使用本机存储的读取性能，先完整拷入本机。

## Mac 安装与导入

- 打开 DMG，把 PJDV M39 拖到可保留它的位置。完整资源版 App 约 42 GB；轻量版 App 需另行导入资源。
- 当前使用本地 ad hoc 签名，尚未 Apple 公证。首次打开按 [Apple 的未公证 App 说明](https://support.apple.com/102445) 检查并批准此 App。
- 轻量版：资源管理里先选择自己的 prod.keys，再选择 XCI，随后选择资源保存位置。可以选外置 SSD；导入完成后会记住位置。
- 已有完整资源：选择“连接已提取资源文件夹”，选同时含 `romfs` / `MEGA39-v1.0.9` 和 `DLC` 的父目录。
- 完整资源版在新设备上可以直接读取 App 内资源。使用外置盘目录时，运行期间保持该盘连接；路径失效后重新选择。

## 键盘映射

Mac 键盘、iPad Magic Keyboard / 外接键盘使用同一套固定映射，按物理 QWERTY 位置读取，目前不做改键面板。

| 键盘 | Switch 输入 |
| --- | --- |
| W | X（上面键） |
| A | Y（左面键） |
| D | A（右面键，确认） |
| S | B（下面键，返回） |
| 方向键 ↑ / ↓ / ← / → | 方向上 / 下 / 左 / 右 |
| I / K / J / L | 方向上 / 下 / 左 / 右 |
| Q / E | L / R |
| Space | X、Y、A、B 同时按下 / 松开 |
| Delete / Backspace（含 Forward Delete），或 P | ＋（暂停） |
| Enter / Return（含数字键盘 Enter），或 M | － |

**Return 不再兼任确认，确认使用 D。** ZL / ZR 暂不做键盘映射，两个摇杆也不提供键盘映射或编辑。支持长按和组合；失去焦点时清理按住状态。

## 手柄与触控测试

- DualSense：圆圈对应 Switch A / 确认，叉号对应 Switch B / 返回；方向键、摇杆、四个面键、L1 / R1 已经用户实测基本正常。
- 游戏震动用《Catch the Wave》测试成功的连续长滑键。EXTREME 开头约 1.7 秒、HARD 约 26.7 秒有可用于验证的长链；只敲普通短滑键不能验证这一路反馈。
- 震动为 GameController / CoreHaptics 的近似转换，尚非位精确的 Switch HD 震动。重连、左右反馈和延迟仍需更多回归。
- DS5 内置扬声器在 Mac / 移动设备上不受支持，游戏音频从设备或耳机输出，参见 [Sony 支持说明](https://www.playstation.com/en-us/support/hardware/pair-dualsense-controller-bluetooth/)。
- 虚拟手柄采用 Switch 布局，当前缩放 200%；有实体手柄时自动隐藏，也可手动开启 / 关闭。
- 主菜单请用方向和确认键；原版菜单文字不是全部都能直接点按。原作 Touch Play 和虚拟按键触控分别验收。

## 建议的测试顺序

1. 冷启动、跳过片头、进入选曲；抽查 EXTREME / EX EXTREME 和服装直接装备，确认原成绩保留。
2. 用《Catch the Wave》检查输入与长链震动；再测暂停 / 恢复、重试、回选曲和手柄断开重连。
3. 用《ゴーストルール》检查持续负载，比较普通放大与 MetalFX，记录画质、卡顿、帧时间、音画同步和温度。
4. 使用“退出游戏”确认保存后，重新启动检查黑屏、残音、闪退和存档。

M4 iPad 早前已完成《ゴーストルール》1080p 三轮、1440p 多轮，正常演奏采样约 60 FPS，但存在少量长间隔与载入停顿。不能据此声称所有歌曲和设备稳定真实 60 FPS。帧率浮窗不能替代长时间帧间隔、温度和音画同步验收。

## 验证范围与已知问题

- 原生 XCI 解密器已对这份 XCI 的全部 **41,943,373,493 bytes** 文件数据完成 IVFC 校验，并逐文件与此前 Python 提取 SHA-256 对照一致；28 个分区的目录指纹、数量和字节总量一致。
- 缺失文件补全、已有资源校验复用、取消 / 续导、格式边界与非法输入检查已测试；不读取或执行 XCI 内的新程序代码，运行程序仍是已适配的版本。
- Mac 已通过系统选择器实际导入并重启恢复目录访问；修复数据目录后已进入原游戏。此前 iPad 版的资源管理与原游戏片头实机启动通过；完整大 XCI 的真机导入仍需本机 / 外置盘输入回归：开发传输通道发送该大文件时中断，不能把此项记作通过。
- 默认解锁已检查真实新档和 M4 旧档，并在真机抽查 EXTREME / EX EXTREME 与服装直接装备；没有逐项玩遍所有歌曲 / 难度 / 服装。
- 全曲画质、反射 / 光照一致性、Touch Play、更多手柄、真实持续 60 FPS、发热与音画 / 判定同步仍需验证。

## 0.1.4 历史验证记录

以下是 0.1.4 的历史证据，不代表 0.1.5 的新提交路径已完成同等真机回归。

- iOS 真机、模拟器和 Mac Catalyst 的 Release 构建通过；输出上限、折叠布局边界、摇杆参数、语言对应、手柄物理顺序和着色器依赖检查通过。
- M4 iPad 真机已检查日语启动页与游戏菜单、Xbox 诊断图标的 YXAB 排列、设置底栏和按键设定。诊断选择只控制图片，不伪造手柄连接，也不改变实际输入映射。
- M4 真机 3D 角色场景的 HDR 采样出现原始浮点峰值 3.625、输出峰值 2.121，证明扩展值实际进入输出；这不代表全曲 HDR 画质已经验收。游戏 HDR 仍默认关闭。

- 已核对翻译目录的键与格式占位符一致，并限制为拥有完整菜单资源的三种可选语言；固定键盘输入和手柄物理位置映射保持不变。
- 游戏画面修复重点是原版资源与渲染行为，不通过修改饱和度或亮度冒充材质修复。
- HDR、舞台 RT 和折叠设备适配均属实验功能。默认 SDR；帧生成实验尚未作用于游戏。
- 部分烘焙在帮助图中的 XYAB 和控制器外形仍可能保留 Switch 图示；这不代表实际输入被交换。
- 更新前备份存档；覆盖安装可保留资源和进度。公开安装包不包含个人存档、prod.keys 或本机开发配置。
